这是什么

这是 LastDreamTeam 独立维护的中文 Fork，不是上游官方内置中文版本。
最初在独立构建目录中应用语言覆盖层；本分支把同一套词库和必要界面改动纳入 Git，方便复现、审查和后续合并。
运行环境不请求在线翻译服务，不修改 Hermes 核心、人设、记忆、凭据或业务数据库。
与未修改上游相比，仍有明确的前端源码差异；不能称为完全零修改或保证上游升级永不冲突。

已包含

- apps/web/messages/zh.json：当前 6,312 条界面词条；初版为 6,304 条，现已做语境化修订并加入 8 项权限撤销确认，不再与首次部署逐字节相同。
- 中文、英文、韩文三语言选择器；优先级为用户语言 Cookie、浏览器语言、默认英文。
- 中文浏览器语言匹配、中文字体回退、网页元信息与聊天日期格式。
- 法律页面的中文导航和标签；不翻译法律正文或改写公司信息。
- 不含具体实例账号、域名、内网端口的通用中文接入指南。
- 语言协商回归测试，以及离线 ICU 参数、标签、分支、内联代码与键集合校验。

翻译来源与质量边界

首次词库使用公开界面文本的机器翻译，并做了 1,038 次术语/词条人工规则覆盖。
这不等于每句均已人工终审。产品名、协议、命令、变量与部分技术标签保留原文。
用户聊天、项目文档、密码和密钥没有进入翻译流程或本次提交。
后续修订以 messages/zh.json 为词库唯一来源；修改后重新执行离线校验。

验证

按上游 CONTRIBUTING.md 安装仓库锁定的依赖后，在仓库根目录执行：
  node scripts/check-zh-locale.cjs
  pnpm exec vitest run apps/web/src/i18n/locale-negotiation.test.ts apps/web/src/i18n/locale-negotiation.guard.test.ts apps/web/src/i18n/locale-zh.test.ts
  pnpm --filter web type-check
  pnpm --filter web build

离线词库检查依赖上游已声明的 @formatjs/icu-messageformat-parser，不增加线上依赖。
初次整理只执行词库、语言协商与语法检查；2026-10-10 后续修复已完成 GitHub CI 全量网页构建和新增交互回归，后端 9 组隔离本地化测试也通过。当前部署组件 SHA、实际公网验收及回滚证据见根目录 README，不能用旧回执替代未来更新后的重新验收。

构建资源

不要直接在负载紧张的生产主机上全量编译。
原部署构建采用 2,560 MiB Node 堆、单构建并发、Next 单 worker，并预留至少 2 GiB 可用内存。
这些是特定环境的经验值，不是最低系统需求或不会 OOM 的保证。
生产使用过的低内存 next.config.ts 参数不属于汉化功能，本提交不强制覆盖 Fork 的构建策略。

更新与回滚

1. 合并上游前保留当前中文提交/网页产物及独立数据备份。
2. 检查新增/删除的英文词条，更新中文并通过 ICU、语言切换与构建检查。
3. 验收登录、看板、聊天、文档、设置及窄屏布局；语言切换不应触发收费模型请求。
4. 回滚界面只回滚本分支提交或网页产物，不覆盖新的项目数据、密码或 Bot 记忆。
5. 如需保持上游工作区干净，可在单独的 Git worktree/构建目录应用本分支差异。

公开发布范围

不含 .env、secrets、数据库、上传文件、聊天、截图、运行日志、私有运维文档或编译产物。
不会修改账号密码，也不会自动切换现有服务器的部署版本。
本分支不改上游继承的 CI 工作流；合并到 main 前应检查自动云部署及容器发布目标，避免沿用上游的生产目标。
