# Sprintable 简体中文接入指南

此指南适用于自建 Sprintable，不包含任何实例的账号、密钥或内部地址。
英文和韩文指南仍然保留；界面语言不会改写项目文档、聊天记录或智能体人设。

## 使用界面

1. 打开管理员提供的网页地址，在语言选择器中选择“简体中文”。
2. 已保存的语言选择优先于浏览器语言；尚未选择时会识别中文浏览器。
3. 用看板管理任务，用目标和冲刺组织工作，用文档保存确认后的方案。
4. 会议中按职责 @ 相应智能体。是否仅在被 @ 时回复，由连接器配置决定，不由汉化包改变。
5. 聊天建议不等于已确认需求；把结论整理为文档、任务和验收标准。

## 接入智能体

接入分为工具连接、消息接收、职责说明三个部分。

- 为每个智能体创建独立的 Sprintable API 密钥，按实例管理员提供的地址配置 MCP。
- 需要接收聊天消息的智能体，还应启用对应的频道或平台连接器。
- 配置所属项目、职责和权限；先验证消息送达，再验证一次只读工具调用。
- “工具已添加”不代表消息通道已经连接，也不代表智能体有权读取所有项目。

不要把自建实例的密钥发送到官方 SaaS，也不要将模型服务商密钥当作 Sprintable 密钥。
不要公开密钥、关闭用户白名单或复用不同智能体的身份来解决接入问题。

## 常见问题

中文未出现：在语言选择器主动选择中文，已保存的 EN/KO 选择具有更高优先级。
工具可用但没有回复：检查消息连接器、事件订阅和用户授权，不只检查 MCP。
重复回复：一条消息可能产生多种服务端事件；连接器应按消息身份去重，不应删除原生事件类型。
鉴权失败：核对实例地址与该智能体的独立密钥，避免把其他服务的凭据混入。
翻译不准确：记录页面和词条，修改 messages/zh.json；不要修改业务数据库内容。

## 更新和回滚

汉化只影响网页界面，不重置用户密码、智能体配置、聊天或项目数据。
升级前备份当前网页产物；回滚界面应恢复旧网页版本，不应覆盖升级后的业务数据。
法律文书正文、公司信息、用户内容和技术协议标识维持原样，中文标签不构成法律译本。
